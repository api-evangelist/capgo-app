Capgo provides a platform to build Capacitor and Ionic apps using AI agents, offering features such as native iOS and Android builds, store publishing, live updates, and integration with MCP skills. The service enables developers to streamline app development and deployment with AI-powered assistance, targeting modern mobile app workflows.

**Areas:** Company · AI · Mobile · Development · Capacitor

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Capgo: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
